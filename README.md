# 🤖 Salão Carmem Carvalho AI

Sistema de atendimento inteligente para WhatsApp desenvolvido para automatizar o atendimento inicial do Salão Carmem Carvalho, utilizando Inteligência Artificial, integração com WhatsApp e transferência para atendimento humano quando necessário.

## ✨ Funcionalidades

* Atendimento automático via WhatsApp
* Integração com OpenAI
* Memória de contexto por cliente
* Personalidade personalizada para o Salão Carmem Carvalho
* Transferência automática para atendimento humano
* Pausa automática da IA durante atendimento humano
* Identificação de clientes durante a conversa
* Controle de IA ligada/desligada
* Estrutura preparada para painel administrativo em React

## 🛠️ Tecnologias Utilizadas

### Backend IA

* Python
* Flask
* OpenAI API

### Integração WhatsApp

* Node.js
* Baileys

### Painel Administrativo

* React
* TypeScript
* Vite

## 🚀 Objetivo

O objetivo do projeto é fornecer um atendimento rápido, organizado e humanizado para clientes do salão, automatizando dúvidas frequentes e permitindo que a equipe assuma a conversa quando necessário.

## 🔒 Segurança

Informações sensíveis, como credenciais, sessões do WhatsApp e chaves da OpenAI, não são armazenadas no repositório.
